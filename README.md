Este projeto é uma landing page responsiva para a "Pindorama Pets", uma clínica veterinária fictícia. Ele foi desenvolvido como desafio final do processo trainee da **Unect** (Empresa Júnior de Engenharia de Software da UTFPR).

---

## 🎯 Sobre o Desafio

O projeto foi desenvolvido em dupla com o objetivo de replicar um protótipo de design fornecido, buscando a maior fidelidade visual e funcional possível.

* **Empresa Júnior:** Unect (UTFPR)
* **Equipe:** Projeto em dupla.
* **Coordenação:** A divisão de tarefas foi definida após uma reunião remota e alinhamentos via Telegram.

### Divisão de Tarefas

O desenvolvimento da landing page foi dividido entre os membros da dupla para cobrir todas as seções do protótipo:

* **Augusto Thiago (Trainee de Comercial):** Responsável pela parte superior da página (Seções: *Header, Hero, Carrossel, Sobre Nós, Nossos Serviços*).

* **Ikaro (Trainee de Desenvolvimento):** Responsável pela parte inferior da página.

> [!NOTE]
> Este repositório contém o **código-fonte completo** da landing page, integrando as contribuições de ambos os desenvolvedores.

---

## ✨ Funcionalidades

* **Layout 100% Responsivo:** Design *mobile-first* que se adapta a tablets e desktops.
* **Menu Hambúrguer:** Menu de navegação funcional em JavaScript para dispositivos móveis.
* **Carrossel Interativo:** Carrossel de banners com controles de navegação e indicadores.
* **Seções Completas:** Inclui todas as seções do protótipo, desde a apresentação até o formulário de contato e rodapé.
* **Estrutura Semântica:** Uso correto de tags HTML5 para melhor acessibilidade e SEO.


---

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estruturação semântica da página.
* **CSS3:** Estilização, layout (Flexbox e Grid) e responsividade (Media Queries).
* **JavaScript (Vanilla):** Utilizado para adicionar interatividade ao menu mobile e ao carrossel.

---

## 🏁 Como Executar

Por ser um projeto web estático, não há necessidade de instalação.

1.  Clone este repositório:
    ```bash
    git clone [https://github.com/thiagoatsl/Pindorama-Pets.git](https://github.com/USUARIO-DA-DUPLA/NOME-DO-REPOSITORIO.git)
    ```
2.  Navegue até a pasta do projeto.
3.  Abra o arquivo `index.html` no seu navegador de preferência.
